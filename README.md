# Portfolio Command Center

A live, auto‑updating portfolio dashboard powered by GitHub Actions and Yahoo Finance.  
It fetches daily closing prices, calculates changes, and displays them in a futuristic, interactive web interface.

## ✨ Features

- **Automated daily updates** – runs after US market close (weekdays).
- **Rich data** – includes price, change, previous close, company name, and category.
- **Interactive UI** – sortable table, search filter, top gainers/losers.
- **Futuristic design** – glassmorphism, dynamic gradients, and smooth animations.
- **Zero‑cost hosting** – deploy on GitHub Pages for free.
